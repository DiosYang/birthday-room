# 星光生日小屋

一个可在 GitHub Pages 托管的纯静态 3D 生日祝福网站。

## 内容

黑猫、更茂盛的花束、小书里的“生日快乐！”，以及月亮来信、留声机、生日礼盒、蛋糕和蜡烛互动。

`index.html` 已包含页面样式和 Three.js，无需构建、后台、外部字体或 GPT 服务。声音由浏览器在点击后合成。Three.js 使用 MIT 许可证，见 `THREE-LICENSE.txt`。

## GitHub Pages 发布

将这些文件放在公开仓库的根目录。在 Settings → Pages 中选择 Deploy from a branch，分支选 main，目录选 / (root)，然后保存。发布成功后使用 Pages 页面给出的真实网址。

访客无需 GitHub 账号。中国大陆网络的可达性和速度需要用实际访问者的网络测试，本项目不保证所有地区均可稳定访问 GitHub Pages。
